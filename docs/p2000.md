# P2000 softwaremodel

P2000 wordt niet op de ESP32 geparsed. De gewenste flow is:

```text
PagerMon/P2000 server -> structured JSON -> HACS/API -> Event Engine -> Layout
```

De mock portal gebruikt payloadvelden voor priority, discipline, rawText, description, street, houseNumber, place, region, capcodes, units, timestamp en incidentId.

Disciplines:

- `FIRE`
- `AMBULANCE`
- `POLICE`
- `MMT`
- `KNRM`
- `OTHER`

De Events-pagina bevat presets voor P1 Brandweer, A1 Ambulance, Politie, Lifeliner en een burst van tien berichten. De algemene Rule Engine kan capcodes, discipline, plaats en priority gebruiken; er is geen tweede P2000-filterengine.

De P1-, P2- en generieke meldingslayouts gebruiken een 3-pixel rand die 4 pixels vanaf de matrixrand naar binnen ligt (x=4, y=4, 120x56). Dit houdt de volledige rand zichtbaar wanneer de paneelhouder de buitenste pixels afdekt. De tekst staat binnen de rand; de browser-preview en ESP32-renderer gebruiken hetzelfde `properties.strokeWidth`-veld.
